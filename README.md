# Engineering Portfolio

PCB design, embedded systems, PLC/HMI automation, and robotics simulation.

## Featured Project · Seismic Exploration Instrument

A concept for a portable three-channel seismic recorder for shallow
subsurface surveys. The design takes signals from three geophones and
displays their waveforms on a shared time axis so users can compare
signal arrival times.

![Seismic recorder connected to three geophones](seismic-exploration-instrument.png)

**Technical focus:** Low-noise analog inputs, synchronized sampling, and
first-arrival analysis.

**Project status:** Design concept. The image uses illustrative waveforms.
